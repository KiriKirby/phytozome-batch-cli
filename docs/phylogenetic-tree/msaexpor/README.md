# `msaexpor` Design Index

`msaexpor` is the PHgo-owned replacement for MSA image export in the JalviewJS MSA page.

The module does not export screenshots of the current UI. It asks the PHgo Jalview bridge to render a clean vector scene from Jalview/SwingJS renderer state, then writes SVG, PNG, or PDF from that scene.

## Core Decisions

- `File -> Export image...` opens the `msaexpor` settings window.
- The window is registered as a Jalview/SwingJS child window so it gets native MSA page layering, drag, resize, and focus behavior.
- The window content is PHgo-owned Fluent-style UI, restyled to match the current MSA child-window look, and hosted inside a same-origin iframe to keep native form controls interactive.
- Export output includes only the MSA alignment board area generated by `msaexpor`.
- Automatic export includes every current MSA row; PHgo green/yellow/red selection state does not implicitly hide rows.
- Automatic export uses one full-width major block when advanced layout is off.
- Preview uses a manual `Refresh preview` action and a dirty-state indicator instead of rerendering on every form edit.
- Residue, group, feature, font, and label styling come from Jalview's current renderer state through the native export bridge.
- Export output must not include temporary UI such as the current cursor/selection rectangle, PHgo row checkboxes, menus, scrollbars, dialogs, or annotations.
- The Jalview-native vector bridge is the only export renderer. If the bridge is unavailable, export fails explicitly.
- SVG is the canonical transparent vector representation. PNG and PDF are derived from the same scene.
- Export scaling is content-relative and affects PNG only. SVG and PDF keep vector logical geometry regardless of Scale.

## Source Files

The first implementation uses these ownership targets:

- `internal/phylo/viewer_assets/assets/jalviewjs/phgo-bridge.js`
  Launch bridge, current MSA-state collection, and menu handoff.
- `internal/phylo/viewer_assets/jalview-bootstrap.html`
  Asset loading and PHgo/Jalview host page.
- `internal/phylo/viewer_assets/assets/msaexpor/index.js`
  PHgo-owned settings UI, DSL parser, data model normalizer, Jalview-native render bridge caller, SVG/PNG export helpers, and PDF handoff.
- `internal/phylo/viewer_assets/assets/msaexpor/pdf.js`
  Single-file browser-global PDF bundle generated from `tree-viewer/src/msaexpor-pdf.js`.
- `internal/phylo/viewer_assets/assets/msaexpor/style.css`
  PHgo/MSA theme for the export window content.
- `internal/phylo/viewer.go`
  Current payload, MSA state, selection, and aligned FASTA HTTP surfaces.
